# Small Church Stack

> Professional tools without enterprise complexity.

## The Philosophy

Small churches (50-200) need:
- **Professional appearance** (no cobbled-together look)
- **Volunteer-friendly** tools
- **Room to grow** without migration headaches
- **Reasonable cost** (under $100/month total)

This stack balances **ease of use** with **feature completeness**.

## The Stack

| Function | Tool | Cost | Why This One |
|----------|------|------|--------------|
| **ChMS** | ChurchApps (Chums) | Free | Modern UI, good support, scales up |
| **Website** | WordPress (self-hosted) | ~$10/mo | Full control, sermon plugins |
| **Presentation** | FreeShow | Free | Modern alternative to ProPresenter |
| **Giving** | ChurchApps Giving | ~2.9% + $0.30/tx | Integrated, lower fees than most |
| **Email** | Google Workspace | $6/user/mo | Professional, familiar |
| **Communication** | ChurchApps app + email | Included | Push notifications |

**Total monthly cost:** ~$20-50  
**Setup time:** 1-2 weeks  
**Technical skill:** WordPress familiar

---

## Migration Path

If coming from [Church Plant Stack](../church-plant/):

1. **Keep:** YouTube for sermons, OpenLP (or upgrade to FreeShow)
2. **Migrate:** Member list from spreadsheet to Chums
3. **Add:** Professional email (Google Workspace)
4. **Upgrade:** WordPress.com → self-hosted WordPress

---

## When to Upgrade Further

Move to custom/enterprise when:
- Attendance consistently **>500**
- You need **multi-site coordination**
- Giving exceeds **$50k/month**
- You have **full-time tech staff**
